# Semana 5 - SpeedFast

Simulación de coordinación de entregas concurrentes con sincronización en Java.

## 📂 Estructura
- `Pedido.java`: clase que representa un pedido.
- `EstadoPedido.java`: enum con estados del pedido.
- `ZonaDeCarga.java`: recurso compartido con sincronización.
- `Repartidor.java`: clase que implementa `Runnable`.
- `Main.java`: clase principal que ejecuta la simulación con `ExecutorService`.
